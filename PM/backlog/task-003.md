# task-003: Design the notification system

## Scope

Review and design application notifications, including how transient messages
behave on screens and in modals, then implement the agreed design in a future
slice.

## Acceptance criteria

- Discuss and agree on when messages should appear, persist, or be dismissed,
  including whether the existing auto-dismissal requirements should change.
- Address layout stability, accessibility, and messages that need user action,
  including save failures.
- Reconcile the approved design with the existing notification requirements
  and implement and verify it after developer approval.

## Context

The developer reported that a briefly displayed save-progress message made the
New Deal modal change size. Removing that message is separate from this task;
the broader notification design remains to be discussed.

The developer approved creating this backlog task on 2026-11-27. The design and
implementation have not been started.
